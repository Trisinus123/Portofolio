# Portofolio React

1. Install Node.js (versi 18 atau lebih baru), lalu jalankan:
   npm install
   npm run dev
2. Edit data di `src/data.js` (nama, proyek, pengalaman, dll).
3. Foto: taruh file di folder `public/`, lalu isi `photo: '/foto.png'` di `src/data.js`.
4. Build: `npm run build`. Isi folder `dist/` bisa di-upload ke GitHub Pages.
